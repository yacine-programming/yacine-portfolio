🖼️ Dossier : images du portfolio

Place ici :
- les images de tes projets (référencées via l'admin, champ "Image")
- ta photo de profil si tu veux en ajouter une

Formats recommandés : .jpg, .png, .webp
Taille recommandée  : 1200×750 px (ratio 16:10)
Poids               : < 200 Ko par image

Pour ajouter une image à un projet via l'admin :
  Admin → Projets → Modifier → champ "Image (chemin)"
  Exemple : assets/images/mon-projet.jpg
